## 📝 简介

欢迎来到**通义点金** 👋

我们是**阿里云金融行业线**的**通义点金团队**，聚焦于大模型在金融行业的探索研究与落地。

### 方法论：点金数据飞轮

我们的工作围绕一个闭环方法论展开 —— **评测 → 数据合成 → 后训练** —— 每一轮循环产出可复用的金融能力，再反哺下一轮：

- **评测** 通过行业级 Benchmark 设定可量化的能力目标。
- **数据合成** 通过可控、可扩展的轨迹数据，将金融行业长期存在的"数据稀缺"问题转化为**"数据可生产"**。
- **后训练**（SFT、RL）将数据转化为稳定、可迁移的任务能力，并反哺评测与数据生成，形成闭环。

### 研究方向

- **金融行业评测** —— 覆盖基础能力（CFLUE）、场景应用（M<sup>3</sup>FinMeeting）、Agentic 任务执行（FinMCP-Bench）的三层能力评测体系，FinGDPVal 共建中。
- **数据合成** —— Agent 蒸馏、Workflow、MCP 环境交互、多智能体 Self-Play 等多种合成方式，支撑 DianJin-R1-Data、CSC 等数据集与训练语料。
- **Post-Training** —— DianJin-R1 推理模型，以及行业首个金融领域过程奖励模型 Fin-PRM。
- **智能对话** —— CSC 客服对话、CARE 情感支持对话，引入显式的认知–情绪–策略推理链路。
- **Agentic** —— DianJin-SKILLS（百技图）技能库、DianJin-TIR 自主规划与工具调用。
- **多模态** —— 面向金融文档理解、推理与工具交错的视觉语言模型（DianJin-OCR-R1）。

**2026 重点方向：** Agentic RL 与 Metaharness 进化。

本仓库是上述工作的开源主页。
